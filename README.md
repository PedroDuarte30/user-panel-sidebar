# ⚡ User Panel Sidebar

A modern, responsive, and collapsible user panel sidebar UI built with pure HTML5, CSS3, Vanilla JavaScript, and Boxicons.

## 🚀 Video Demo
Watch the full short on YouTube: [@digitalmind9976](https://youtube.com/@digitalmind9976)

## 🛠️ Built With
* HTML5
* CSS3 (Transitions & Modern Layout)
* Vanilla JavaScript
* [Boxicons](https://boxicons.com/)

## 📂 How to Use
1. Clone or download this repository.
2. Open `index.html` directly in your browser.
